To run the Batch process we need to have Redis and Celery running as Background tasks
./run.sh

celery worker -A worm_cat_app.celery --loglevel=debug --concurrency=4
celery worker -A worm_cat_app.celery --loglevel=info

Redis must be running
./run-redis.sh
